# Velvet Bourbon

A noir merge puzzle: combine numbers, read their next moves, and manage tension.

- [Play in Telegram](https://t.me/velvetbourbonbot) — open the bot and tap **Играть** in the chat menu.
- [Play in your browser](https://kikikikier.github.io/velvet-bourbon/).

This repository contains the compiled static game for GitHub Pages. Progress is stored locally on the device. The bot opens the game through its menu button; the game does not require a running bot server.

No bot tokens, operator tools or server credentials are included. Font license notices are distributed with the game assets.
